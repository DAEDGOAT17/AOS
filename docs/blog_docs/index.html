Welcome to AOS Documentation

AOS is a from-scratch x86_64 operating-system research prototype. This guide covers boot, memory, drivers, filesystems, the shell, and its bounded AI-assisted agent runtime.

Model inference runs through a local Ollama-compatible host service; AOS owns tool validation, execution, observations, and persistent Lisp tools. Start with the newcomer guide, then follow source links in the generated function glossary.
